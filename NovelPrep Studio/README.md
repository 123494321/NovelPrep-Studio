# NovelPrep Studio (소설 원고 전처리 & EPUB 역변환 스튜디오)

> **독립형 소설 원고 전처리 및 정규화 웹 툴**  
> `EPUB Studio (v2.2.5)`의 완성된 코어를 일절 건드리지 않고, 전처리 작업에 특화되어 완전 분리된 독립 프로젝트입니다.

---

## 🌟 핵심 기능 2대 축

### 1. 링크 기반 목차 수집 & 단방향 순차 탐색 회차 번호 주입기
- **목차 자동 수집**: 소설 연재 목록 URL을 입력하여 회차 소제목을 일괄 수집합니다. (HTML 소스 파싱 및 텍스트 직접 입력/붙여넣기, 북마크릿 보조 지원)
- **단방향 순차 전진 탐색 (Sequential Forward Search)**: 이전 소제목을 찾은 위치 이후부터만 다음 회차를 탐색하므로, 본문 대화/복선/서술에 소제목과 동일한 단어가 우연히 등장하더라도 오매칭을 원천 차단합니다.
- **원문 100% 보존 원칙**: 작가가 의도한 빈 줄(장면 전환 연출), 특수문자, 문장부호 등 본문 내용은 단 1글자도 변경하지 않고, 오직 식별된 소제목 위치에 `[1화]. 소제목` 규격 번호만 안전하게 삽입합니다.
- **유연한 패턴 매칭**: 소제목 뒤 부호(`(1)`, `[1]`, `- 1 -`), 띄어쓰기 차이를 유연하게 식별합니다.

### 2. 구형 EPUB ➔ 순수 TXT 고품질 역변환기
- **비표준 태그 정제**: 외부 사이트나 구형 변환기로 제작된 `.epub` 파일의 난잡한 HTML 태그(`div`, `p`, 인라인 스타일, 불필요한 엔티티)를 완전 정제합니다.
- **문단 호흡 복원**: 작가의 원래 문단 호흡과 줄바꿈 구조(빈 줄 1개 유지 등)를 자연스럽게 살려낸 순수 `.txt` 원고로 복원합니다.
- **내부 이미지 원본 추출**: 전자책 내부의 표지 및 삽화 이미지를 원본 파일 그대로 분리 추출하여 이미지 단독 ZIP 및 TXT 통합 패키지 ZIP으로 다운로드할 수 있습니다.

## 🚀 EPUB Studio (v2.2.5)와의 연계 워크플로우

```
[비표준 소설 원고 / 구형 EPUB]
              │
              ▼
   ┌──────────────────────┐
   │   NovelPrep Studio   │ ➔ 회차 번호 정규화 & 순수 TXT 복원
   └──────────────────────┘
              │ [완성본 TXT 다운로드]
              ▼
   ┌──────────────────────┐
   │  EPUB Studio v2.2.5  │ ➔ 패턴 원클릭 분석 & 출간용 전자책 제작 완료
   └──────────────────────┘
```

1. **NovelPrep Studio**에서 번호 없는 원고에 `[1화]. 소제목` 규격 번호를 주입합니다.
2. 우측 상단의 **[EPUB Studio 열기]** 버튼을 눌러 EPUB Studio로 이동합니다.
3. 생성된 `[정규화]_원고.txt` 파일을 EPUB Studio에 등록하고 **[목차 형식 분석]**을 누르면 1초 만에 전체 목차가 자동 인식되어 전자책 제작이 완성됩니다.

## 🛠 실행 방법
- 별도의 웹 서버나 설치 과정 없이 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 실행할 수 있습니다.
- 모든 연산은 브라우저 로컬 메모리에서 100% 처리되므로 외부 서버 전송이 없어 원고의 저작권과 개인정보가 안전하게 보호됩니다.
